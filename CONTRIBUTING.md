# Contributing

Please see the [Contributing Guide](docs/guides/contributing.md) for detailed information on how to contribute to this Knowledge Base.

## Quick Start

1. Use the appropriate template from the `templates/` folder
2. Follow the naming conventions (kebab-case)
3. Include proper metadata and tags
4. Test your documentation before submitting
5. Update related index files

## Questions?

Create an issue or reach out to the maintainers.

Thank you for contributing! 🙏
