# Send To Customization

The Send To context menu is backed by a real folder that you can edit freely.

## Notes

- Open the folder with `shell:SendTo` in the Run dialog (`Win+R`)
- Add a shortcut here to make it appear in Send To for the current user
- Remove shortcuts to declutter the menu
- Typical additions: a folder shortcut, a compressed (zipped) folder target, Notepad
- There is no all-users Send To folder in modern Windows; each profile has its own
