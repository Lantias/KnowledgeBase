# Common Environment Variables

A quick reference for the built-in Windows environment variables you encounter most often.

## Notes

- `%USERPROFILE%` – current user's home directory (e.g. `C:\Users\Alice`)
- `%APPDATA%` – roaming application data (`%USERPROFILE%\AppData\Roaming`)
- `%LOCALAPPDATA%` – local application data (`%USERPROFILE%\AppData\Local`)
- `%TEMP%` / `%TMP%` – per-user temporary files directory
- `%SystemRoot%` – Windows installation directory (usually `C:\Windows`)
- `%ProgramFiles%` – 64-bit program files directory
- `%ProgramFiles(x86)%` – 32-bit program files directory on 64-bit Windows
- `%PATH%` – ordered list of directories searched for executables
- `%COMPUTERNAME%` – machine's NetBIOS name
- `%USERNAME%` – currently logged-on user name
